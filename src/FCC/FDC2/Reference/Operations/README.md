# FDC2 Commands

Commands specific to the [FDC2](../../README.md) application of the [system extension](../../../FCE/System.md).
For the broader command set, see [Commands](../../../Reference/Operations/README.md).

| Type | Command | Processor | Description |
|------|---------|-----------|-------------|
| `F_FDC2` | [`PROVE`](Prove.md) | Instruction | Processes an FDC2 attestation request, collecting data-provider signatures and producing a signed proof. |
