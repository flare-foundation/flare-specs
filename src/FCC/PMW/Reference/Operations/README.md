# PMW Commands

Commands specific to the [PMW](../../README.md) application of the [system extension](../../../FCE/System.md).
For the broader command set, see [Commands](../../../Reference/Operations/README.md).

| Type | Command | Processor | Description |
|------|---------|-----------|-------------|
| `F_XRP` | [`PAY`](Pay.md) | Instruction | Signs an XRP Ledger multisig payment transaction using TEE-managed keys. |
| `F_XRP` | [`REISSUE`](Reissue.md) | Instruction | Re-signs a previously issued XRP payment for resubmission. |
